# Virtus Dei est

Первый рабочий каркас приложения для анализа скриншотов «Случайные числа» и последующего фактического тиража.

## Уже есть
- тёмный рабочий интерфейс без страницы входа;
- загрузка любого количества скриншотов;
- мобильная адаптация;
- подготовка к облачному Supabase Storage/Postgres, без LocalStorage как основной базы;
- схема таблиц для тиражей, скриншотов, сравнений и обучающих наблюдений;
- серверный шаблон `stoloto-sync` с переменными `STOLOTO_LOGIN` и `STOLOTO_PASSWORD`;
- логика сравнения скриншота с тиражом и фиксации «ухода от скриншотов».

## Пока не подключено
1. Реальный OCR конкретного экрана Столото. Нельзя подставлять придуманные числа: модуль должен выдавать VERIFIED только при 10 уникальных числах 1..80.
2. Реальный автоматический вход/получение тиражей Столото — сначала нужно проверить актуальный поток входа, CAPTCHA/2FA и источник данных.
3. Отдельный Supabase проект для Virtus Dei est.

## Запуск
```bash
npm install
npm run dev
```

Скопируйте `.env.example` в `.env` и добавьте URL + publishable key отдельного Supabase проекта.
