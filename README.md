# Virtus Dei est

Рабочий каркас приложения для изучения связи между скриншотами Столото «Случайные числа» и фактическими тиражами КЕНО.

## Подключено
- отдельный Supabase-проект `Virtus Dei`;
- облачная PostgreSQL-база и приватное хранилище скриншотов;
- GitHub Secrets `STOLOTOLOGIN` и `STOLOTOPASSWORD` используются только в GitHub Actions;
- автоматическая синхронизация завершённых тиражей КЕНО со Столото каждые 10 минут;
- рабочий Edge Function `draw-ingest` с проверкой: ровно 20 уникальных чисел 1..80;
- автоматический триггер: новый тираж → сравнение со всеми VERIFIED-скриншотами этого тиража → запись совпадений и «ухода от скриншотов» → новое обучающее наблюдение;
- загрузка изображений через Edge Function `screenshot-upload` в `virtus-screenshots`;
- клиентский OCR Tesseract.js: VERIFIED ставится только если распознано ровно 10 уникальных чисел 1..80;
- Edge Function `screenshot-ocr` сохраняет результат OCR в базе;
- тёмный интерфейс без отдельной страницы входа в Virtus Dei;
- количество скриншотов перед тиражом не ограничивается фиксированным пакетом.

## Проверенный автоматический поток
27.09.2026 GitHub Actions успешно получил завершённый тираж КЕНО №328402 со Столото и записал 20 чисел в Supabase. Следующие запуски выполняются по расписанию.

## Важно для OCR
Общий OCR уже подключён, но распознавание конкретного макета «Случайные числа» нужно откалибровать на реальных скриншотах пользователя. До калибровки сомнительный результат получает `review`, а не `verified`.

## Логика обучения
1. Скриншот фиксируется до тиража и сохраняется в облако.
2. OCR извлекает числа; только 10/10 переводит запись в VERIFIED.
3. После появления результата тиража backend автоматически считает пересечение.
4. Для каждого скриншота сохраняются совпавшие числа и числа тиража, которых не было на скриншоте.
5. Для всего набора перед тиражом сохраняются частоты чисел, числа, которые вообще не предлагались, покрытие фактического тиража и обучающие признаки.
6. История не переписывается задним числом.

## Локальный запуск
```bash
npm install
npm run dev
```

Supabase по умолчанию уже указан в приложении. `.env.example` можно использовать для переопределения окружения.
